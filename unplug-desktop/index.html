Built for Creators & Players

  • Game Workshop: Code HTML5 canvas games in the built-in editor with instant live sandbox execution.
  • Simulated Ad Economy: Encounter rewarded ads on game over, watch 5-second simulated video ads to earn extra lives and hints, or toggle Ad-Free pass.
  • Contract Verification: Automatically validates HTML5 sandbox safety, 256 KiB size limits, inline script rules, and readiness handshakes.
  • Android APK Bridge: Push newly written games directly to the Android app source (apps/android/www/games/) and trigger Gradle APK builds.
  • Desktop Arcade: Play all bundled games in a full desktop arcade experience offline.
