UNPLUG Desktop

A connected workspace for game developers and administrators. Submit games, review tested candidates, monitor releases, and manage approved updates.

In development · Windows first

Get the desktop app

The Windows installer is being prepared. Supported Windows versions, processor architecture, file size, and installation instructions will accompany the first tested release.

View the Desktop repository

One connected publishing platform

The desktop workspace and Android player will use the same hosted UNPLUG service. Developer access covers their own games; administrator access includes platform-wide review and release controls.

Browser installation is also planned

The browser-installable PWA remains a planned option alongside the Windows download. A PWA installs from its hosted web address; its manifest is not an executable installer. The web workspace link will be added when that service is available.
