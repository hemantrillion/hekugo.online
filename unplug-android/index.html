UNPLUG Android

A game library built for playing on your phone. Planned features include verified game downloads, offline play, and online catalog updates.

Native Capacitor Shell & PWA Offline Player

Get UNPLUG on Mobile

UNPLUG is available immediately as an offline-first PWA for mobile browsers, and as a native Android project powered by Capacitor.

Launch Mobile Web Player (Offline PWA)

Native Android Project (Capacitor):

The native Android project is generated in apps/android/android/. To compile or inspect in Android Studio:

cd apps/android && npx cap open android

Configured with target API 34, strict CSP, and native asset bundling for Google Play compliance.

View the GameStore repository

Connected when available. Offline after download.

The planned app connects to the UNPLUG service for accounts, the live catalog, and approved updates. Successfully downloaded offline games will remain playable without a connection. Online games and publishing services require internet access.

Direct APK downloads from HeKuGo are one distribution channel. Google Play distribution is planned for a later release.
